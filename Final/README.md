# 🎬 Movie Search — Konsolen-App für die Sakila-Datenbank

Интерактивное консольное приложение для поиска фильмов по базе данных **Sakila (MySQL)**
с логированием запросов в **MongoDB**.

---

## Структура проекта

```
movie_search/
├── .env                  # Конфигурация подключений (не коммитить!)
├── main.py               # Точка входа, интерактивное меню
├── sql_requests.py       # Подключение к MySQL, поиск фильмов (генераторы)
├── log_search_hist.py    # MongoBase + SearchLogger (запись истории)
├── log_search.py         # SearchStats (статистика из MongoDB)
├── formatter_UI.py       # Форматирование вывода (таблицы, меню, история)
└── README.md             # Этот файл
```

## Быстрый старт

### 1. Установить зависимости

```bash
pip install pymysql pymongo python-dotenv colorama
```

### 2. Настроить .env

Файл `.env` уже содержит правильные данные для подключения к учебным базам.
При необходимости отредактируйте:

```env
# MySQL (Sakila)
DB_HOST=ich-db.edu.itcareerhub.de
DB_PORT=3306
DB_NAME=sakila
DB_USER=ich1
DB_PASSWORD=password
DB_PAGE_SIZE=10          # Фильмов на одну страницу результатов

# MongoDB (логи)
MONGO_URI=mongodb://ich_editor:verystrongpassword@mongo.itcareerhub.de/...
MONGO_DB=final_project_121225_oleg_v
MONGO_COLLECTION=search_history
```

### 3. Запустить

```bash
python main.py
```

## Возможности

| Пункт меню | Описание |
|---|---|
| **1** | Поиск по ключевому слову в названии фильма (постранично, по 10) |
| **2** | Поиск по жанру + диапазону лет (с подсказками из БД) |
| **3** | ТОП-5 самых частых поисковых запросов |

| **0** | Выход |

## Архитектурные решения

- **Генераторы** (`_paginate`) — постраничный обход БД без загрузки в память
- **Property / setter** — инкапсуляция `__page_size`, `__config`
- **Наследование** — `SearchStats` и `SearchLogger` используют `MongoBase` (DRY)
- **Параметризованные запросы** — `%s`-плейсхолдеры, SQL-инъекции невозможны
- **SOLID** — каждый класс/функция отвечает за одно действие
- **Вывод через `__str__`** — форматтеры возвращают строки, `print()` — только в `main.py`
